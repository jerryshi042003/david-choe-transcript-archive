# Editorial records

These files match Claude’s `choe-corpus/editorial@1` ingest contract. They are
written commentary over timestamped source transcripts, not replacements for
what was said.

Editorial rules:

- summarize arguments and episode structure without silently rewriting dialogue;
- use chapter timestamps only where the source transcript supports the turn;
- keep people, places, works, and themes as retrieval metadata;
- describe connections as editorial hypotheses with a traceable source basis;
- verify exact quotations against the recording before publication.
